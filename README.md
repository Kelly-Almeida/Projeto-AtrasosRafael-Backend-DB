## 📌 Sobre o Projeto

Este projeto foi desenvolvido com um objetivo muito claro: **registrar e exibir, em tempo real, os atrasos do ilustríssimo Professor Rafael Costa** na Escola SENAI Anchieta.

### 🥪 A Verdadeira Motivação
Tudo começou com a nossa constante batalha contra o relógio no horário de almoço. Quando somamos:
1. 🚶‍♂️ **Tempo de trajeto** até o refeitório;
2. 🧍‍♂️ **Fila astronômica** do micro-ondas;
3. ♨️ **Tempo para esquentar** a marmita;

...nos sobram exatamente **pouquíssimos minutos** para engolir a comida e voltar a tempo. Cada minuto de atraso no início do intervalo vale ouro!

---

## ⚖️ Disclaimer / Aviso Importante

> 🚨 **Atenção:** Este é um projeto feito **puramente na brincadeira**. Não temos o objetivo de depredar, manchar ou arruinar a imagem e reputação do **Professor Rafael Cunha**. 
> 
> Trata-se de uma sátira com tom irônico e humorístico criada entre nós três como uma piada interna e uma forma leve de lidar com a nossa frustração diária. Respeitamos o professor e sua aula! ❤️

## 📊 Funcionalidades do Dashboard

- [x] **Calendário do Atraso:** Mapeamento mensal dos dias em que a aula atrasou.
- [ ] **Contador de Minutos Percebidos:** Cálculo do impacto direto no tempo útil de almoço.
- [x] **Estatísticas de Precisão:** Histórico de frequência e pontualidade.
